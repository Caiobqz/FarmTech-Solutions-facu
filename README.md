# FarmTech Solutions

Projeto acadêmico desenvolvido para a atividade da FIAP com o objetivo de aplicar conceitos de programação e análise de dados a um cenário de Agricultura Digital.

## Objetivo

Desenvolver uma aplicação para auxiliar no gerenciamento de duas culturas agrícolas:

- Soja
- Café

## Aplicação em Python

O sistema em Python será responsável por:

- Cadastrar dados da fazenda e da cultura;
- Calcular a área de plantio;
- Calcular a quantidade necessária de insumos;
- Armazenar os registros em listas/vetores;
- Visualizar os dados cadastrados;
- Atualizar registros;
- Excluir registros;
- Utilizar estruturas de decisão e repetição.

### Cálculos utilizados

**Soja:** a área de plantio é calculada considerando um terreno retangular.

**Café:** a área de plantio é calculada considerando uma área circular. O manejo de insumos considera o número de ruas da lavoura, o comprimento de cada rua e a quantidade de produto aplicada por metro.

## Aplicação em R

A próxima etapa do projeto utilizará os dados da aplicação para realizar análises estatísticas básicas em R, incluindo:

- Média;
- Desvio padrão.

Como etapa adicional, o projeto poderá consumir uma API meteorológica pública utilizando R para consultar e exibir informações climáticas.
